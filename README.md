## 🚀 Featured Work

### Real-Time Cognitive Workload Estimation (HRI)
- Built a real-time AI system combining gaze tracking and entropy modeling  
- Processed ~1.79M gaze samples across 20 participants  
- Achieved strong correlation with human-reported cognitive load (Spearman ρ = 0.71)  
- Deployed using ROS + Docker with sub-150ms latency  
- Designed for adaptive robotics and human-aware AI systems  

### Gaze + Entropy Tracking System
- Real-time ROS-based pipeline for cognitive signal processing  
- Live entropy computation via streaming topics  
- Integrated interactive experiments and behavioral logging
